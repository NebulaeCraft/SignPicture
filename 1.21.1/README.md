# SignPicture for Minecraft 1.21.1 Fabric

将构建产物和适用于 Minecraft 1.21.1 的 Fabric API 放进客户端的 `mods` 文件夹。需要 Java 21 或更高版本，以及 Fabric Loader 0.19.5 或更高版本。

旧牌子升级到 1.21.1 后，客户端会读取牌子各面的四行文字。支持旧版 `#地址{参数}`、`#$域名/路径{参数}`（HTTPS）、`地址[参数]` 和 `#!资源位置{参数}`。图片保留尺寸、位置、旋转、裁切、透明度等静态参数。图片牌子的渲染距离为 128 格，所在区块需要已加载。

**空手右键图片牌子**（主手和副手都为空），可以操作当前朝向的一面。对面是图片而当前面为空时，也可以重试对面的图片。

- **Reload / 重新加载** 优先重新读取本地图片缓存。缓存缺失时从原地址下载。
- **Redownload / 重新下载** 直接请求原地址，在下载并解码成功后替换缓存。资源包图片使用 Reload。

当前支持 PNG、JPEG 等 Java ImageIO 可解码的静态图片。GIF 显示首帧，旧版牌子动画使用初始帧参数。自定义混合模式、纹理重复开关和 mipmap 参数未移植。Fabric 版的缓存位于客户端目录下的 `signpic/fabric-cache/`。

## 构建

构建使用 JDK 25，产物面向 Java 21。在仓库根目录执行以下命令。Windows 可以用 `1.21.1\gradlew.bat -p 1.21.1 build`。

```sh
bash 1.21.1/gradlew -p 1.21.1 build
```

可安装的 JAR 位于 `1.21.1/build/libs/`。
